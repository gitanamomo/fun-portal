## 🚀 部署与访问方式

### 方案 1：Vercel 一键上线（推荐）
点击上方 **Deploy with Vercel** 徽章，登录您的 Vercel 账号，选择该仓库，无需任何构建配置即可自动部署获得全球高速加速域名（如 `https://fun-portal.vercel.app`）。

### 方案 2：GitHub Pages 直接访问
在 GitHub 仓库中开启 Pages 功能（Source 选择 `Deploy from a branch -> main`），即可在 `https://gitanamomo.github.io/fun-portal/` 畅快访问。

### 方案 3：本地零依赖直接看
无需安装任何复杂环境，直接双击打开项目根目录下的 `index.html` 即可畅快体验！
